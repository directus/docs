The Flows page lets you organize your Flows into folders, search and filter the list, duplicate an existing Flow, and import and export Flows.

## Organize Flows into Folders

![The Flows folder sidebar](% Screenshot of the Flows folder sidebar %)

Use the folder sidebar to group related Flows. The sidebar is resizable and can be collapsed to give the canvas more room.

- **Create a folder** — Select **Create Folder** in the header bar and give it a name.
- **Rename or delete a folder** — Open the folder's context menu.
- **Move Flows** — Select one or more Flows and choose **Move Folder** to place them in a folder or send them back to the root.

The selected folder is stored in the page URL, so you can bookmark or share a link to a specific folder.

::callout{icon="i-lucide-info"}
Deleting a folder does not delete the Flows inside it. Those Flows return to the root of the Flows page.
::

## Search and Filter Flows

![Searching and filtering Flows](% Screenshot of searching and filtering Flows %)

Use the search box to find Flows by name, and the filter control to narrow the list down to the Flows you want to work with.

## Duplicate a Flow

![Duplicating a Flow](% Screenshot of duplicating a Flow %)

To copy a Flow along with all of its operations, open the Flow's context menu and select **Duplicate**. The copy is placed in the same folder as the original.

::callout{icon="i-lucide-info"}
A duplicated Flow is always created with an **inactive** status so it will not run until you review and activate it.
::

## Export a Flow

![Exporting a Flow](% Screenshot of exporting a Flow %)

To save a Flow as a file, open the Flow's context menu and select **Export Flow**. This downloads a JSON file containing the Flow and its operations, which you can store in version control or import into another project.

Exporting a Flow requires an administrator account.

## Import a Flow

![Importing a Flow](% Screenshot of importing a Flow %)

To add a Flow from a file, select **Import Flow** in the header bar and choose a JSON file that was previously exported. If a folder is open when you import, the Flow is placed in that folder.

::callout{icon="i-lucide-triangle-alert" color="warning"}
**Imported Flows start inactive**
An imported Flow is always set to an **inactive** status. Review it before you activate it, so it does not operate on live data before you are ready.
::
