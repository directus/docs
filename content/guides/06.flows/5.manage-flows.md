The Flows page lets you organize your Flows into folders, search and filter the list, duplicate an existing Flow, and import and export Flows.

## Organize Flows into Folders

![Creating a folder on the Flows page](/img/857d4e58-24b5-4a8c-be42-eed011b95164.webp)

Use the folder sidebar to group related Flows. The sidebar is resizable and can be collapsed to give the canvas more room.

- **Create a folder** — Select **Create Folder** in the header bar and give it a name.
- **Rename or delete a folder** — Open the folder's context menu.
- **Move Flows** — Select one or more Flows and choose **Move Folder**.

The selected folder is stored in the page URL, so you can bookmark or share a link to a specific folder.

::callout{icon="i-lucide-info"}
Deleting a folder does not delete the Flows inside it. Those Flows return to the root of the Flows page.
::

## Search and Filter Flows

![Searching and filtering Flows](/img/166bfc26-b9c0-4609-82da-6c7930d226dc.webp)

Use the search box to find Flows by name, and the filter control to narrow down the list.

## Duplicate a Flow

To copy a Flow along with all of its operations, open the Flow's context menu and select **Duplicate**. The copy is placed in the same folder as the original.

::callout{icon="i-lucide-info"}
A duplicated Flow is always created with an **inactive** status so it will not run until you review and activate it.
::

## Export a Flow

![The Flow context menu with the Export Flow option](/img/f8004890-d889-4a24-a168-c1cbb48ee435.webp)

To export a Flow, open the Flow's context menu and select **Export Flow**. This downloads a JSON file containing the Flow and its operations.

## Import a Flow

![Importing a Flow](/img/64dc472d-3846-4d3e-84fa-9bd708096017.webp)

To import a Flow, select **Import Flow** in the header bar and choose a JSON file that was previously exported. If a folder is open when you import, the Flow is placed in that folder.

::callout{icon="i-lucide-triangle-alert" color="warning"}
**Review an imported Flow before activating it**
An imported Flow is always set to an **inactive** status, so it will not run until you activate it. If it references collections that do not exist in your project, update those operations to use collections that are available.
::
